# Discord 精準清理

[繁體中文](README.md) | [English](README.en.md)

![Discord 精準清理：只刪自身訊息，單則分頁預覽](assets/intro.png)

只清理**目前這隻 AstrBot 機器人自己發出的訊息**。選好時間範圍或訊息 ID／連結，查看清單，再由原操作者按下確認。身分以 Discord 回傳的作者 ID 為準，支援一般訊息、斜線指令回覆與帶 webhook 標記的自身訊息；群友、其他機器人及其他作者的 webhook 訊息均排除。

- 使用 Discord **原生 `/dc_clean` 斜線指令**。預覽、四個按鈕、進度、取消與完成結果全程在頻道內**只有操作者能看見**，更新同一則私人訊息，不留下公開完成提示，也不另發私訊。
- 支援 Discord 伺服器文字頻道與討論串，限定目前頻道；不支援私訊或跨頻道清理。
- 操作者必須是 **AstrBot 登記的管理員**（目前會話配置的 `admins_id`），預覽與確認都重新檢查。不需要 Discord 頻道管理員或「管理訊息」權限。機器人使用現有登入連線，不需要再填 Token。
- 確認鎖定預覽中的 ID；刪除前重新讀取並比對作者、內容、附件與嵌入資訊，已變更者跳過。
- 不提供 LLM 工具、不呼叫模型、不自動清理，也不會停止其他插件的刷屏來源。

## 安裝

需要 AstrBot **4.29.4+**、Python **3.12+** 及已連線的 Discord adapter。使用 AstrBot 現有 Pycord，沒有額外執行依賴。

將發布 ZIP 透過 WebUI 安裝，或將本目錄放到 `data/plugins/astrbot_plugin_discord_cleanup`，重載插件。Discord adapter 必須開啟「指令註冊」並已同步 `/dc_clean`；若指令選單沒有它，先啟用指令註冊，再於 WebUI 停用、啟用 Discord 平台連線以重新同步。不需更動或重新輸入機器人 Token。

更新至 v0.1.5 後重載插件，再從 Discord 指令選單選擇 `/dc_clean`。已有原生指令時不需重啟 AstrBot 或重新連線 Discord。舊預覽全部失效，請重新建立私人預覽。

也可在 AstrBot WebUI 透過公開倉庫網址安裝：

```text
https://github.com/xiangerwu/astrbot_plugin_discord_cleanup
```

`metadata.yaml` 已標註僅支援 Discord，標籤為「Discord、訊息管理、清理」。公開 GitHub 倉庫與插件市場上架是不同步驟；市場發布方式見[發布說明](docs/publishing.md)。

## 使用

在 Discord 輸入 `/dc_clean` 後，**從跳出的機器人指令選單選中它**，再於 `params` 欄位貼時間或訊息 ID／連結。直接當普通文字貼出、加喚醒前綴或 @ Bot 均不會執行清理，也不會產生公開回覆。這是為了確保從第一則回覆起全程私密。

自動辨識時間範圍或指定訊息；不填參數、輸入 `help` 或格式錯誤時私人顯示用法。請先確認你的 Discord 使用者 ID 已加入 AstrBot 管理員設定，只有 Discord 管理權限不會獲准。下方範例表示原生指令及 `params` 的內容。

### 指定時間

```text
/dc_clean 2026-11-08T04:07 2026-11-08T04:09
```

開始時間包含在內，結束時間不包含在內；未填時區以 **UTC+08:00** 解讀。也可使用 `2026-11-07T20:07:00Z` 或帶時區偏移的 ISO 時間。請填完整日期，避免把凌晨訊息選到錯的一天。

### 指定訊息

```text
/dc_clean 123456789012345678 123456789012345679
/dc_clean https://discord.com/channels/伺服器ID/目前頻道ID/訊息ID
```

以上數字是格式示例，使用時換成實際 ID。多筆 ID／完整連結可混合，用空格或逗號分隔。Discord 右鍵訊息可「複製訊息連結」；複製 ID 需開啟開發者模式。

每次最多 **100 個不同的訊息 ID／連結**，重複目標只計一次；第 101 個不同目標會拒絕整次選取。完整連結較長，仍受 Discord 輸入長度限制，可改貼較短的訊息 ID，或縮小時間範圍。

AstrBot 4.29.4 將插件斜線指令的參數放在單一 `params` 欄位：選擇 `/dc_clean` 後填兩個時間，或填訊息 ID／連結清單。留空會顯示用法。

### 預覽與確認

1. 預覽顯示總數、略過數、訊息 ID、時間及內容摘要。每頁 5 筆，按上一頁／下一頁只更新原訊息。
2. 只有原操作者能按「確認刪除全部 N 則」或「取消」。**確認會刪整份清單，不只是本頁。**
3. 清單 5 分鐘後失效；重新預覽會取代自己在同一頻道的舊清單。重載插件也會取消待確認清單。
4. 完成後原本的私人預覽直接改為刪除／略過／失敗統計與紀錄編號。取消與中斷訊息也更新同一則私人訊息；不再發一則結果、不留下公開狀態。若操作中斷，請重新預覽剩餘訊息。

v0.1.2 修正 AstrBot 4.29.4 未將按鈕事件交給插件的問題，四個按鈕均改由按鈕事件處理器接收。上一頁在首頁停用、下一頁在末頁停用；單頁時這兩個按鈕同時停用屬正常行為。從 v0.1.1 更新後重載插件並重新執行 `/dc_clean`，舊預覽不再有效；此修正不需重新連線 Discord。

v0.1.4 將自身訊息資格統一為作者 ID 等於目前機器人 ID，不再因 webhook、應用程式或互動中繼資料而排除自身訊息。預覽與刪除前均核對作者及頻道，不能只靠名稱、頭像或 bot 標記。更新後重載插件並重新預覽即可。

私人預覽使用 Discord ephemeral 回覆，只有發出原生指令的人能看見。無權使用按鈕的提示也僅對點擊者可見。插件不會刪除使用者的普通文字指令訊息。

## 範圍與紀錄

每次最多 100 則目標；時間查詢最多讀取 1000 則頻道訊息，超限就要求縮小範圍，不會悄悄刪除部分清單。逐則刪除自己的訊息，不使用「清空最近 N 則」或批次刪除端點，亦不受批次端點的兩週限制。

機器人需能檢視頻道、讀取歷史、發送訊息及使用討論串；只刪自己的訊息不要求它具有「管理訊息」權限。操作者的授權僅依 AstrBot 管理員設定；若預覽後被移出名單，確認也會被拒絕。

確認後、第一次刪除前，資料目錄會保存 `data/plugin_data/astrbot_plugin_discord_cleanup/cleanup-編號.jsonl`：操作者、作者、頻道、訊息 ID、文字、附件名稱／URL、嵌入資料及逐筆結果。紀錄不含 Token、不下載附件，附件 URL 可能失效，**不是可復原訊息的備份**。Discord 刪除不可復原。紀錄不自動清除，請由管理員依自己的保留需求處理，勿放入公開倉庫。
